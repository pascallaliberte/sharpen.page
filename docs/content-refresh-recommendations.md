# Content refresh recommendations

Working doc for sharpen.page (not published). Generated as part of the SEO Build Mode pass. Descriptions and hubs already shipped; this guide is for **body refreshes** you do over time.

## Sitewide checklist

1. After deploy: confirm [sitemap.xml](https://sharpen.page/sitemap.xml) lists new hubs (`/jtbd/`, `/about/`, etc.) and no longer lists `/404/`.
2. Optional: verify the property in Google Search Console and submit the sitemap (no Analytics required).
3. Refresh the **10 priority posts** below first (real body edits + set `last_modified_at` in front matter when you do).
4. Restart a light publishing cadence; don’t mass-bump dates without substance.
5. Privacy/terms pages remain optional; add if you want stronger trust signals.

## About page — what to add later

The live `/about/` page is intentionally minimal. When you’re ready, consider writing (yourself — don’t invent):

- **Background:** how you came to JTBD / product sharpening (short narrative).
- **How you work:** interview style, synthesis deliverables, engagement shape (without a public price list if you prefer).
- **Selected proof:** clients or collaborators *with permission* (Brian Casel / Clarityflow and Julian Rubisch quotes already appear elsewhere — decide what belongs on About).
- **Credentials / training:** only what you’re comfortable stating.
- **Relationship to pascallaliberte.me:** one clear sentence.
- **Photo:** alternate crop or larger portrait if avatar feels small on About.
- **FAQ:** e.g. remote vs on-site, who it’s for, how Ten relates to paid research.

## Refresh classes

| Class | Meaning |
|-------|---------|
| `evergreen-polish` | Soften newsletter openers; light CTA/link updates |
| `update-links` | External resources likely stale |
| `showcase-status` | Label dead/pivoted showcase sites; keep analysis |
| `time-bound-frame` | Pandemic/recession framing note if refreshing |
| `tool-update` | Tool/builder mentions may need a reality check |
| `low-priority-skip` | Skip unless you have a reason |
| `rewrite-candidate` | Larger rewrite worth considering later |
